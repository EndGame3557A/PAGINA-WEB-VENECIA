# PAGINA-WEB-VENECIA
PAGINA WEB DE LA PIZZERIA VENECIA DE TULUÁ
Este es un proyecto de ejemplo creado con XAMPP y subido a GitHub.

Descripción
Este proyecto es una página web básica que se puede acceder desde un servidor local o desde GitHub Pages.

Características
Página web básica con HTML, CSS y PHP
Configurado para funcionar con XAMPP
Subido a GitHub Pages
Requisitos
XAMPP instalado en la computadora
Cuenta de GitHub para subir el proyecto
Instrucciones
Clona el repositorio en tu computadora
Abre el archivo index.html en un navegador para ver la página web
Edita los archivos HTML, CSS y PHP para personalizar la página web
